# Strelka chat

Прототип чат - сервра на Java с регистрацией, аутентификацией и историей сообщений

## Технологии
- Java 17
- PostgreSQL
- BCrypt
- Maven

## Возможности 
- Регистрация и вход пользователя
- Общий чат с рассылкой сообщений
- Личные сообщения
- Смена ника
- Сохранение истории сообщений
- История

## Запуск
1. Установить PostgreSQL и создать БД 'chatserver'
2. Создать 'config.properties' - вставить туда содержимое `src/main/resources/config.properties.example` и заменить на свои данные.
3. Собрать проект: 'mvn clean package'.
4. Запустить сервер - `java -jar target/chat-server-1.0-SNAPSHOT-jar-with-dependencies.jar`.

## Команды
- `/register <логин> <пароль> <ник>` — регистрация
- `/login <логин> <пароль>` — вход
- `/nick <новый_ник>` — сменить ник
- `/w <получатель> <сообщение>` — личное сообщение
- `/history` — история публичных сообщений
  - `/history privayte` - история приватных сообщений
  - `/history <Никнейм>` - история приватных сообщений с конкретным пользователем
- `/online` - список онлайн пользователей в чате
- `/exit` — выход
